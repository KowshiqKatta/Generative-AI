style(ui): warm dark theme, borderless assistant messages, quieter chrome

The mint accent on near-black read as a terminal, and both message types
were boxed identically, which made the reading surface feel like a form.

- New palette: warm near-black canvas with a muted clay accent, all as
  CSS variables in assets/style.css.
- Assistant messages render flat on the canvas with no container; only
  the user turn gets a raised card. Avatars become hairline circles.
- Accent now marks the active session rather than filling call-to-action
  buttons, so colour carries information.
- Inter for UI, Newsreader for the H1; body line-height raised for long
  answers.
- Emoji removed from structural chrome; sidebar headings are small-caps
  labels. Progress-panel emoji kept, where they carry signal.
- Hairline borders, transparent expanders, thin scrollbars, Deploy
  button hidden.
- _inject_css() no-ops if the stylesheet is missing. Copy assets/ and
  .streamlit/ into the image.
